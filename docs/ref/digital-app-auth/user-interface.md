## ユーザーインターフェース
デジタルアプリケーション認証チェックのステータスは、ダッシュボードのヘッダーチェックのアイコンの横に表示されます。


デジタル・アプリケーション認証が含まれていないモデルには、追加のアイコンは表示されません：

```{image} ../_static/digital_app_auth_na.png
:alt: User interface for passing check of digital application authentication
:scale: 100 %
:align: center
```

デジタル・アプリケーション認証が正しく実装され、エクスポート後にダウンストリームで変更されていないソフトウェア・ツールのモデルには、有効なチェックを示す追加のアイコンが表示されます：



```{image} ../_static/digital_app_auth_valid.png
:alt: User interface for passing check of digital application authentication
:scale: 100 %
:align: center
```

デジタル・アプリケーション認証が正しく実装されていない、またはエクスポート後にダウンストリームで変更されたソフトウェア・ツールのモデルは、チェックに失敗したことを示す追加のアイコンが表示されます：



```{image} ../_static/digital_app_auth_invalid.png
:alt: User interface for passing check of digital application authentication
:scale: 100 %
:align: center
:border: 4px
```
