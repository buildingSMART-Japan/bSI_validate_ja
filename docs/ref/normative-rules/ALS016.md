# ALS016
この業界のベスト・プラクティス・ルールは、連続する `IfcCurveSegment`アライメント表現を構成するエンティティ間の幾何学的連続性を評価する。


このルールは形状表現（ジオメトリ）のみをチェックし、アライメントのセマンティック（ビジネスロジック）定義の情報は利用しない。


[`IfcCurveSegment`](https://standards.buildingsmart.org/IFC/RELEASE/IFC4_3/HTML/lexical/IfcCurveSegment.htm) `Transition`属性は、モデル作成者が意図したセグメント間の連続性を決定するために利用される。




`.CONTINUOUS.`の値は ALS016 の警告が位置の不連続性だけ(接線性ではなく)発生することを意味します。同様に、`.DISCONTINUOUS.`の値は ALS016 の警告は出せないことを意味します。
